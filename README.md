# 🧠 Grow My Therapy - Dr. Maya Reynolds, PsyD

Grow My Therapy is a professional, fully responsive web application built for the private clinical psychology practice of Dr. Maya Reynolds, PsyD. Designed with a strong emphasis on accessibility, brand identity, and user trust, this platform serves as the digital front door for prospective clients seeking mental health services.

---

## 🚀 Features

- **Responsive Architecture:** Flawless layout scaling across mobile, tablet, and desktop devices.
- **Accessible UI:** Built with WCAG compliance in mind to ensure readability and usability for all users.
- **Modern Brand Identity:** Features a soothing, professional color palette and typography tailored for the psychology and wellness sector.
- **Optimized Performance:** Fast load times and smooth scroll animations for a premium user experience.

## 🛠️ Prerequisites

Before running this project, ensure you have the following installed:

- **Node.js** (v18 or higher)
- **Git**

---

## 💻 Installation Guide (Run Locally)

Follow these steps to run the project on your own computer.

### 1️⃣ Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/piyushmauryacodes/grow-my-therapy.git
cd grow-my-therapy
```

### 2️⃣ Install Dependencies

Install the required Node.js libraries:

```bash
npm install
```

### 3️⃣ Run the Application

Start the local development server:

```bash
npm run dev
```

Open your browser and visit the localhost link provided in your terminal  
(usually: http://localhost:5173)

## 🌍 Deployment Guide (Go Live)

This frontend application is optimized for deployment on **Vercel**.

### Step 1️⃣ Push to GitHub

If starting fresh, run:

```bash
git init
git add .
git commit -m "Initial commit for Grow My Therapy"
git branch -M main
git remote add origin https://github.com/piyushmauryacodes/grow-my-therapy.git
git push -u origin main
```

### Step 2️⃣ Deploy on Vercel

1. Log in to your Vercel account.
2. Click **Add New → Project**.
3. Import the `grow-my-therapy` repository.
4. Leave the default Vite/React settings as they are.
5. Click **Deploy**.

Your professional site is now live! 🚀
